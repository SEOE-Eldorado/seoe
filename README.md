# SEOE Wallet 🅿️

Sistema Electrónico de Operación de Estacionamiento — Gestión inteligente de estacionamiento para municipios.

## Stack

- **Frontend:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, Shadcn/ui
- **Backend:** Firebase (Auth, Firestore, Cloud Functions, FCM)
- **PWA:** next-pwa, Capacitor (Android)
- **Testing:** Vitest, Playwright
- **Monitoreo:** Sentry
- **i18n:** next-intl (es/en)

## Quick Start

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).
